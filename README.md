# ECG-TransUNet

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.20051167.svg)](https://doi.org/10.5281/zenodo.20051167)

This repository contains the training code for **ECG-TransUNet**, our ECG heartbeat annotation and correction network.

The open-source package is intentionally lightweight and keeps only the files required for model training and fine-tuning.

## Overview

The ECG-TransUNet workflow consists of three model branches: **base**, **gan**, and **gan-base**.

Each branch is trained in two stages:

1. **Initial training**
   Train the branch-specific model from the public training dataset bundle.
2. **Correction fine-tuning**
   Fine-tune the corresponding branch on the curated high-quality correction dataset.

Final R-peak predictions are generated by joint inference across the three trained branches rather than by using a single model output.

## Inference

The released workflow is not a single-model inference pipeline.

- The base, gan, and gan-base branches are trained separately.
- Each branch contributes its own corrected prediction after fine-tuning.
- Final R-peak outputs are produced through joint inference across all three trained branches.

## Scope

This repository is the **model-specific training repository** for ECG-TransUNet.

It is narrower in scope than the broader processing repository and is intended for:

- multi-branch model training
- branch-wise correction fine-tuning
- joint inference across the three trained branches
- model-related utilities directly required by training
